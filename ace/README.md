# ACE Applications

This directory contains the actual final ACE source projects exported from the working Toolkit workspace:

- `BANKA_APP`
- `BANKB_APP`
- `IPN_GATEWAY_APP`
- `LOGGING_APP`

Import these projects into IBM App Connect Enterprise Toolkit.

Do not import the original local Integration Server work directory; create a new local Integration Server on the target machine and deploy these applications.

See `../RUNBOOK.md` for the complete setup sequence and `../docs/source-audit.md` for source-specific notes.
